# 出来去哪玩（WQWN）· 最终交付说明

面向「约朋友出门却不知道去哪」的场景：发现城市里好玩的地点、看别人的真实评价、找搭子一起出门。
**纯前端可运行原型**：零构建、零依赖安装、无后端，数据存于浏览器 `localStorage`（key：`wqwn.v3`），刷新/重开浏览器数据不丢。视觉已整体重构为「城市漫游手册」编辑设计风格（暖纸底、宋体标题、等宽元信息、细线分割、大图与留白）。

设计预览：[七视图总览](docs/screens/_overview.jpg)；单页截图见 [docs/screens](docs/screens/)（含第五标签「今天去哪」）。

---

## 一、运行

```bash
# 方式一：本地静态服务器（推荐）
cd D:\VibeCoding\出来去哪玩
python -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080/

# 方式二：npx
npx serve .

# 方式三：直接双击 index.html（file:// 下可用，定位能力受限）
```

- 外部 JS：高德 JS API 2.0（地图，CDN，需 Key，失败自动降级 Leaflet 1.9.4 + OSM 底图，再失败降级内置 SVG 示意图，标记仍可点击）。
- **所有图片均为本地 JPEG 素材**（`assets/photos/`），无外链图片；断网也能完整显示。图片来源与授权见 [assets/photos/CREDITS.md](assets/photos/CREDITS.md)。
- 首次打开为种子数据：5 个用户 / 46 个地点（杭州 10 + 成都 8 + 上海 8 + 广州 20）/ 4 个搭子 / 142 条评论（114 条带图）；另有 13 条打卡记录、10 条实况、9 条避雷标记。
- 默认身份为种子用户 `u1`（昵称见「我的」头像卡）。可在「我的 → 切换演示身份」切换，用「重置演示数据」回到初始状态。

## 三、测试步骤（按功能走查，约 15 分钟）

> 建议先「我的 → 重置演示数据」恢复初始状态，再按顺序走。

**1. 首页地图聚合与联动**
打开首页：地图默认以当前城市杭州为中心展示地点，可拖动/缩放；下方为编辑式地点卡列表（大图 + 编号 + 标题 + 引用评价 + 元信息）。全站共有 46 个地点，分布在杭州 / 成都 / 上海 / 广州四座城市。
- 点地图标记 → 对应卡片高亮并滚动到位；点卡片「查看详情 →」→ 进入详情。
- 地图标题右侧「全部城市 / ALL」下拉可切换杭州 / 成都 / 上海 / 广州：切换后地图重新居中、列表只显示该城市地点。广州中心默认落在珠江新城平月路 161 号（活动演示点），选「广州」后应看到 20 个地点；点「3km」可见珠江公园、天河公园、猎德大桥、花城广场、省博物馆、广州图书馆、珠江琶醍、活力无限KTV等周边去处；点「5km」可再看到广州大剧院；在搜索框输入「平月路」可直接筛出 8 个活动点周边地点。
- 点「在高德地图搜『广州 周边好玩的』↗」→ 新窗口打开高德 URI 搜索（无需 API Key）。
- 断网后刷新 → 地图应退化为纸张色城市示意图，标记仍可点击，页面不白屏。

**2. 附近筛选**
允许定位后卡片显示「距我」，拒绝定位则提示「定位不可用，已使用默认位置」并以杭州为中心。
切换分类 chips（第一行「按题材」：全部/美食/玩乐/自然风景/拍照打卡/夜生活/其他；第二行「娱乐设施」：KTV/剧本杀/密室逃脱/桌游/电玩城/影院/Livehouse）与距离档位（500m/1km/3km/5km/不限）、输入搜索词 → 结果数与卡片实时变化；组合出空结果时应显示空态与「清除筛选」。

**3. 「大家都在夸」横滑**
首页口碑条显示当前城市的 6 条高赞评论（选择「全部城市」时为全站）。
- 6 条以横向卡片排列，可用**鼠标滚轮**横向滚动，或**按住拖拽**滑动（光标变抓手）；
- 点任一条 → 跳到对应地点详情。

**4. 详情页（沉浸式编辑版）**
任取一个地点进入详情，自检：
- 顶部约 408px 大图，标题/分类/价格·距离压在图上；右上两个悬浮按钮（收藏、点赞），左上 ← 返回；
- 图片 ≥2 张时可横滑，底部指示点跟随；
- 紧接一行四项数字：评论数 / 浏览量 / 点赞 / 收藏；
- 「导航前往」按钮在地址行右侧，点击打开高德 URI；
- 下方依次为：避雷提示（WARNING）→ 城市护照打卡卡 → 地址行 → INFORMATION 信息表 → ABOUT 关于简介 → 实况速报（LIVE）→ 真实评价评论区；
- 评论区包含星级选择、文字输入、最多 3 张配图与「发布评论」按钮。

**5. 点赞与收藏**
点 🤍 → 变为 ❤ 且数字 +1，再点恢复；刷新后状态保持。
点 ☆ → 变为 ★ 且 `📌` 数字 +1，toast 提示「已收藏」；再点取消。刷新后保持。

**6. 评论（含配图）**
在详情页评论区：选星级（默认 5 星）、留空提交 → 提示「评论内容不能为空」；输入超过 200 字 → 提示超限；正常提交 → 新评论置顶显示。
点九宫格选 1–3 张图 → 提交后评论下方显示 72px 缩略图；点第 4 张 → 提示「最多 3 张照片」。自己发的评论可见「删除」，删除后列表即时更新。

**7. 地点发布**
「发布」页填表：只填分类直接提交 → 名称/分类/地址/坐标处出现红色提示且不创建。
正常填写（名称 2–40 字、分类、城市、地址、经纬度可点「用当前位置填充」、价格、九宫格选封面、描述、标签）→ 提交成功跳转新地点详情，首页列表与地图同步出现。

**8. 搭子发布与申请**
「搭子」页点「＋ 发起搭子」：集合时间填过去时间或人数填 1/21 → 被拦截；正常发布后新搭子出现在广场，成员显示 1/x。
打开一个非自己发起的搭子 → 填留言与联系方式申请 → 出现「待审批」；重复申请/已是成员/已满员分别给出对应提示。

**9. 搭子审批**
以发起人身份打开自己发起的搭子（种子中 `b1` 带一条待审批申请）→ 点「同意」→ 成员 +1；人数达上限后状态变「已满员」并停止接受申请。
用「我的 → 切换演示身份」可切换到其他用户复现。

**10. 个人中心**
头像卡、四项统计（发布/发起/加入/点赞）、六个分段（我的发布、护照、我发起的搭子含待审批角标、我加入的搭子、我的申请、我点赞过）均可切换，点条目跳对应详情；每个分区为空时有占位与去处按钮。「护照」分段展示打卡统计、城市印章与 6 枚徽章进度。
「切换演示身份」后页面刷新；「重置演示数据」确认后回到初始 46 地点 / 4 搭子。

**11. 今天去哪（第五标签）**
点「去哪」→ `#/whereto`，首次进入应自动翻签，约 0.6–0.9 秒后出现一张随机地点卡（编号、分类、标题、城市·价格、最高赞评价）。
- 点心情 chips（今天想：都可以/吃点好的/玩点新鲜的/看看风景/拍点照片/夜游一下/随便逛逛）或「想玩什么」设施 chips（KTV/剧本杀/密室逃脱/桌游/电玩城/看电影/看演出）→ 只在该分类内重抽，chip 高亮且 `aria-pressed` 正确；
- 连点「再摇一次」→ 相邻两次结果不允许重复；只剩一个地点时提示「签筒里只剩这一张了。」；
- 点「就去这里 →」→ 进入该地点详情，标题一致；返回或切 tab 再回「去哪」应保留本次结果与心情；刷新页面重新抽签。

**12. 底部导航**
依次点「首页 / 去哪 / 发布 / 搭子 / 我的」五个 tab，页面必须立即切换（不依赖浏览器改 hash），当前 tab 高亮；中间的「发布」保持橙色圆形凸起按钮。

**13. 持久化与旧数据兼容**
发布地点、点赞、收藏、发评论后刷新页面 → 数据仍在；关闭标签页重开仍在。
浏览器控制台执行 `localStorage.setItem('wqwn.v3', JSON.stringify({version:2,currentUserId:'u1',users:[],spots:[],buddies:[]}))` 后刷新 → 不应报错/白屏（缺字段会被自动补齐）。

**14. 桌面端**
窗口拉宽到 ≥720px：页面变为居中的 430px 手机画布（细边框 + 柔和投影 + 暖灰桌面底），页面整体滚动，tabbar 固定在底部且可点。

**15. 避雷与实况（R13）**
打开 `#/spot/s1`：四项数字后应先看到「WARNING / 避雷提示」（2 人踩过雷、标签计数、最新一条），再是护照打卡卡、地址、信息、关于、实况速报（2 条）、评论。
- 点「我也踩过雷」→ 选「排队太久」「交通不便」并写一句备注 → 提交，人数 +1、出现「我的标记」；点「修改」改标签保存，人数不变；点「取消」确认后人数还原。
- 打开无避雷地点（如 `#/spot/s4`）应显示「暂无避雷标记，你来做第一个提醒者」。
- 在 `#/spot/s1` 点「+ 发一条实况」→ 空内容提交提示「写点什么再发布吧」；输入内容并选最多 3 张图库照片发布，新实况出现在第一条并带图；本人可删除；打开无实况地点可看到「还没有实况」空态。

**16. 城市探索护照打卡（R10）**
先「我的 → 重置演示数据」。打开 `#/spot/s1` 应显示「已打卡 ✓」与「全国 5 人 · 本地点 2 人打卡」；打开 `#/spot/s3` 点「打卡签到」→ toast「打卡成功 · 第 3 个脚印」，卡片变为已打卡；再点无效、不重复写入。
进入「我的 → 护照」：封面统计应为打卡地点 03 / 到访城市 01 / 连续天数 03 / 获得徽章 01（以种子 + 刚打卡为准）；城市印章可点回地点详情；徽章墙 6 枚显示「已获得」或 `current / target` 进度；刷新页面后数据保持。

**17. 图片放大（灯箱）**
在首页点任一地点卡封面图、在详情页点头图 / 评论配图 / 实况配图，图片应以黑底灯箱居中放大，底部显示说明文字；滚轮可缩放（1×–4×，以鼠标位置为锚点），放大后按住拖动查看，双击或「复位」按钮回到 1×；点右上角「×」、点黑底区域或按 `Esc` 关闭，页面滚动不被误触；移动端点 × 或黑底可关闭，点图片本身不误关。

## 六、已知限制

- 首页地图默认高德 JS API 2.0（Key 在 `js/map.js`）；脚本加载失败或超时 5s 自动回退 Leaflet + OSM，再失败回退 SVG 示意图。高德 Key 的安全域名需与访问域名一致（当前本地为 `127.0.0.1`）。
- 坐标按 WGS-84 近似记录；高德分支渲染前会转换为 GCJ-02，Leaflet/OSM 使用 WGS-84，不同底图间可能有米级差异。
- 浏览量每次进入详情 +1，重复刷新会累加，无去重窗口。
- 收藏/点赞为单用户本地态，换浏览器或清 localStorage 会回到种子状态。
- 桌面端（≥720px）为居中手机画布，不是独立响应式布局。

## 九、前端页面风格基线（2026-11-14 记录）

整体定位为 **「城市漫游手册 / Editorial City Guide」**：暖纸底、墨色正文、朱砂橙点睛、宋体大标题、等宽元信息、编号制、1px 细线、大图留白；像一本可交互的城市杂志，不是通用 App 卡片风。

核心规范：
- **色彩**：`--paper:#f1efea`、`--ink:#111110`、`--accent:#e85d2a`、`--muted:#6f6b62`、`--line:#d7d1c4`；黑底区块用于重点段落，朱砂橙只做点睛。
- **字体**：标题 / 品牌 / 大数字用宋体（`--serif`），正文用无衬线（`--sans`），英文标签、编号、日期、meta 用等宽（`--mono`）。
- **布局**：430px 移动画布 + 20px 页边距 + 64px 固定底栏；5 个 tab，中间为朱砂圆形发布按钮；桌面端保留居中手机画布，不做全屏重排。
- **组件**：方角 1px 墨线按钮、胶囊 chip、细线卡片、编号 section-head、黑白 Hero；避免通用圆角卡片、玻璃拟态、彩色渐变和重阴影。
- **图像**：本地 JPEG 暖调处理（`saturate(.78) contrast(1.04) sepia(.08)`），点击可开黑底灯箱。
- **新增页面 / 地图重做 / 娱乐设施等改造都必须沿用此基线**；如果要改风格，先与用户确认。

完整版见 [docs/team/frontend-style.md](docs/team/frontend-style.md)（含 token 表、字阶、组件、页面级要点、动效、实现约定与「不要做」清单）。
